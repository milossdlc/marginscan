# Tests

## Test 1 - Filter the Pinnacle working table [sanity]
Viewport: desktop (1280x800)
Covers: /api/sharp/movements, resilient active-league discovery, Pinnacle-only collection, market/line identity, Today, current price range, minimum drop, sorting, reset, /api/sharp/history details
Description: Verify the primary scanner operates on actual latest pre-match observations.
Steps:
1. Open Sharp Scanner and press Reset. Verify Today, all leagues, all real markets, odds 1.01–2.50 and minimum drop 8%.
2. Select Match winner, then Over / Under. Every visible row must match the market; totals must show Over or Under and the actual line. A truthful empty state is valid.
3. Select a league, Next 24 hours, minimum drop 15%, odds to 1.50 and sort by Current odds. Check all rows satisfy the filters and are sorted ascending. No duplicate fixture/selection/line rows may appear.
4. Press Reset. If rows exist, open Details and Price history; verify saved snapshots and the explanation that Opening is first captured, not a verified bookmaker opening. Otherwise verify tracked fixtures and qualifying movements are distinguished with no synthetic rows.
Expected: Filtered rows use latest fresh Current prices, preserve original Signal in details, and display real markets only. Reset restores defaults.

4. Return to Sharp Scanner. No started match may be listed. If no eligible watchlist rows exist, verify the explicit empty state.
Expected: Watchlist survives scanner filter changes, retains distinct market movers after kickoff, and shows no in-play prices or betting recommendations.

Expected: Saved paths are retained; missing or stale closing evidence does not contribute to closing analytics. Empty dates show no invented statistics.
